## 固定范围与发布门

1. 开发期只跑受影响回归，检查通过及时推源码；复用已签 CUDA／Vulkan 包，最后统一编译候选，避免反复全量构建。
2. 冻结一个候选 SHA 后，执行**完整原 68 项纪要语料**：收集语义失败，执行错误／超时／坏报告立即失败；原语料与断言不缩减，全部通过才满足此门。随后完成真实录音、停止、笔记追改及安装升级验收。
3. Mac 验证 Metal／CPU、原生窗口与 M 系列；Windows 验证音频、CUDA／CPU；Linux／Omarchy 验证音频、窗口操作及可用 GPU／CPU。共享 CI 不代替设备结果。
4. 小版本逐步交付，下一候选通过后再估发布时间。差分更新、完整说话人重构、新模型／新后端研究独立推进，不扩大本次发布范围。
