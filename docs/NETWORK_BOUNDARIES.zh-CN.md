# OmaScribe 的联网边界

录音、音频解码、转写、说话人分析和 AI 纪要使用这台电脑上的模型。网络权限只用于用户主动选择的模型下载和在线配置推荐。开启这些权限不会把会议处理切换成云端推理。

## 哪些操作会联网

| 操作 | 处理位置 | 联网行为与内容 |
| --- | --- | --- |
| 录音、暂停、继续、回听 | 本机 | 不需要外部网络；音频保存到本机 |
| 导入并解码音频 | 本机 | 不读取音频文件里引用的 HTTP 等网络资源 |
| 转写、说话人分析、纪要 | 本机 | 模型读取本地文件；录音、转写、笔记、术语和记忆不发送到外部服务 |
| 本机硬件检测、内置模型搭配建议 | 本机 | 不需要上传机器信息，也不需要联网 |
| 导出或导入配置 JSON | 本机 | 不上传文件；先预览、后应用，缺失模型另行下载 |
| 模型下载 | GitHub / Hugging Face 等目录中固定的模型源 | 需要单独开启模型下载权限；服务端会收到普通下载请求，包括 IP 地址和所请求的模型文件，不包含会议内容 |
| 浏览官网配置广场与在线推荐 | 浏览器与官网 | 浏览器向网站发送普通网页请求。浏览与分享是用户主动操作，不在后台上传会议资料 |
| 主动分享配置与性能记录 | 官网 | 仅提交用户预览后选择分享的设置、配置名称、可选硬件信息和性能指标；不会自动附加录音或提示词 |

界面中的“本地推理”指内容处理留在本机，不代表网站访问和模型下载没有网络请求。模型与运行时安装完成后，可以关闭网络权限继续处理会议。

## 设备级开关与共享配置分离

`network-policy.json` 位于应用数据目录，包含三个独立开关，首次启动默认关闭：

```json
{
  "allow_model_downloads": false,
  "allow_online_recommendations": false
}
```

它不属于可分享的 `Profile`。别人的配置不能开启网络权限，不能指定服务器地址、下载链接、程序路径或命令。损坏、超大或包含未知字段的网络策略文件不会被当成授权；在线操作会被阻止，用户可在本机设置中重新保存策略。关闭模型下载权限会请求取消正在进行的下载；已经发出的下载请求可能需要等待当前读取结束或超时才退出。

网站联动只将受限制的配置内容交给应用的导入预览。链接中的配置不会被自动应用，不会下载模型或提交会议任务；应用冷启动时，原有自动任务仍按现有设置恢复。即使配置来自官网，也按外部输入进行字段、大小、范围和模型 ID 校验。

## 实现边界

- 桌面 WebView 的内容安全策略不允许外部脚本、字体、图片或 HTTP 数据请求。模型官方图标保存为应用/网站的同源静态资源，不用热链接追踪用户访问。
- LLM 服务只监听 `127.0.0.1`，使用每次生成新建的鉴权令牌。本机 HTTP 客户端禁用环境代理，不跟随重定向。这个地址用于本机进程通信，不是云端推理。
- 模型目录来自内置目录或已验证的下载目录。共享配置只选择应用支持的 ID；下载内容需要通过长度与 SHA-256 校验后才安装。
- FFmpeg 输入协议限定为 `file,pipe`。即使本地文件实际是播放列表，也不能通过内嵌 URL 访问网络。该选项及嵌套协议行为见 [FFmpeg 官方协议说明](https://ffmpeg.org/ffmpeg-protocols.html)。
- 共享配置与私人资料导出是两个操作。私人资料导出包含笔记、术语和记忆，不能作为公共配置上传。配置名及说明由用户填写，分享前应允许查看完整内容。
- 性能分享只接收规定的硬件、模型、运行参数与数值指标；原始生成文本、提示词、会议标题、路径、数据库和调试日志不属于性能记录。

这些是应用处理路径与输入边界，不是操作系统防火墙。模型下载权限不允许更换任意执行程序；应用也不把“本地保存”等同于“应用级加密”。现有本机数据保护说明见 [SECURITY.md](../SECURITY.md)。

## 回归验收

1. 新安装默认不能下载模型或请求在线推荐。只开启一个开关，另一个操作仍被拒绝；重启后保持设备上的选择。
2. 导入含 `allow_model_downloads`、`network_policy`、任意 URL、路径或命令的共享配置，必须拒绝且不改变设备权限。正常共享配置打开时只显示预览。
3. 读取损坏、未知字段或超过 4 KiB 的网络策略文件，在线操作必须失败；不能退回允许联网的默认值。
4. 用一个实际本地 HTTP 监听器和包含远程片段的本地 HLS 列表验证解码：应出现协议拒绝，监听器收到的连接数为零。正常 MP3/M4A 仍能解码出有效 PCM。
5. 在无外部网络条件下，对已安装模型跑固定人工样本的转写、说话人分析和纪要；界面可报告缺少模型，但不得隐式下载或切换云端。
6. 用包含外部链接和指令文本的转写/笔记检查生成：文本只能作为数据，不能触发网页访问、执行命令或在线推荐。
7. 模型下载与网站接口使用独立的数据类型；性能记录和配置提交测试应拒绝会议正文、音频、日志与未知字段。

本边界以 OmaScribe 自有源码和定向测试为依据。录音、转写与纪要生成不能发送到云端；联网许可仅用于独立的模型下载、配置浏览与软件更新，不能由导入配置代为开启。

0.3.1 新增 `allow_update_checks`，默认关闭，只用于用户手动检查/下载 GitHub 签名安装包。关闭会取消请求；不发送录音、笔记或设备信息，配置分享不能开启。安装会验证签名及签署版本，并要求录音与处理任务结束。详见 [更新说明](UPDATES.md)。
