# OmaScribe 0.3.2

正式版 / Stable release.

- 实时显示新增本地翻译：原文、双语、中译英、英译中四种模式。翻译只在录音与纪要空闲时使用本机模型补上，从不改动原始转写；修改转写后旧译文自动失效重译。
- 纪要语言独立设置（自动／中文／英文），与界面语言分开；双语字幕始终与同一句原文配对。
- 删除可恢复：笔记、说话人与会议删除均需确认；会议进入“已删除”，可在设置 → 存储空间恢复，录音与原文保留在本机。
- 底栏移除，录音计时、音量波形、实时转写与实时字幕开关、说话人和会议文件并入一条会话栏；小窗口（740×560）下控件保持可见可点。
- 侧栏不再显示隐私提示块；设置页保留隐私与联网说明。
- 纪要复核新增相对日期引导：模型引用“今天／下周”等相对日期时必须给出对应出处，否则删除时间词，避免小模型反复提交被校验拒绝。

Live display gains on-device translation in four modes (original, bilingual, ZH→EN, EN→ZH); translations run on the local model only while recording and writing are idle, never alter the transcript, and expire when a passage is edited. Minutes language is a separate setting, and bilingual captions stay paired with their source line. Deletions of notes, speakers and meetings are confirmed and recoverable with audio and originals intact. The footer is replaced by one session strip carrying the recording clock, level waveform and live-view toggles, usable down to 740×560. The writer repair pass now steers relative-date citations instead of resubmitting rejected drafts.

## 升级 / Upgrade

**0.3.1 可在设置 → 软件更新中直接升级到 0.3.2（首次应用内升级）。0.3.0 没有更新器，需先手动安装一次。** Debian 系统包通过包管理器更新。

0.3.1 installs can upgrade in-app through Settings → Software updates; this is the first over-the-air upgrade path. 0.3.0 has no updater and needs one manual install. Update requests fetch only public version metadata and signed installers from GitHub. They send no audio, transcripts, notes, private configuration or hardware information. Recording, transcription and AI minutes remain offline. Shared profiles cannot enable update permission. Installation preserves the separate user-data directory.

安装包内置 Zipformer Small、Qwen3 1.7B Q4_K_M 及运行环境。OTA 校验签名与系统发行者签名不同：macOS 仍为临时签名、尚未公证；Windows 仍无发行者证书。其他平台限制见 [安装与验证说明](https://github.com/EazyLee30/omascribe/blob/v0.3.2/docs/NATIVE_TESTING.md)。
