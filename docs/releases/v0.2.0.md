Native desktop test preview for **macOS Apple Silicon, macOS Intel, and Windows x64**. All installers are compiled by GitHub Actions on their native operating systems, after Linux CI passes for the same commit.

- Native CoreAudio/WASAPI microphone capture, pause/resume, and multiple recording takes in one meeting.
- Bundled offline ASR, Qwen3-1.7B Q4_K_M and CPU inference runtime. WAV import needs no extra software. Windows includes the offline WebView2 installer.
- Finder/Explorer access to each recording and transcript, floating transcript, configurable desktop captions, and Cmd/Ctrl shortcuts.
- Automatic keyword-guided documents with evidence links, bounded repair, streaming timeout handling, and the Linux fixes from 0.1.1/0.1.2.

**Choose your installer:** `macOS-AppleSilicon.dmg`, `macOS-Intel.dmg`, or `Windows-x64.exe`. The packages include models and are large. macOS 11+; Windows 10/11 x64; Intel/Windows CPUs require AVX2.

**Signing:** macOS uses an ad-hoc signature and is not notarized. Windows has no publisher certificate. See the [installation and physical-device test guide](https://github.com/EazyLee30/omascribe/blob/v0.2.0/docs/NATIVE_TESTING.md) for first launch, microphone permissions and known limitations.

CI checks include core tests, strict Clippy, installed-resource discovery, public-speech multi-take/retranscription, real-model Chinese/English document fixtures, and a desktop startup smoke test. Per-platform validation ZIPs and SHA-256 checksums accompany the installers. Physical microphones, permission dialogs, visual behavior and long-session performance still need user testing.

Linux remains the hardware-tested baseline. The source installation workflow continues to be available; this release does not replace Linux system libraries or desktop configuration.
