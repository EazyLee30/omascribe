# OmaScribe 0.3.1

正式版 / Stable release.

- macOS 移除独立应用名标题栏，保留原生红黄绿按钮；会议操作与栏位开关融入内容顶部。
- 固定窗口外层，笔记与转写在栏内滚动，避免底部回弹露出白条。
- 修复中文口述时间与数字时间的等价校验。复核时重新从待处理转写生成，避免小模型重复错误的说话人归属；来源和事实校验继续保留。
- “关注”改为本地分词与关键词排序，不再把整行笔记当关键词。显式加粗的短关键词仍优先使用。
- 设置新增“软件更新”：独立联网许可、手动检查与下载、签名和版本校验、下载进度及取消、安装并重启。录音或内容处理期间阻止安装。

macOS uses a unified window surface with native traffic lights. Workspace overscroll is disabled. Local keyword extraction and evidence-guided repair improve minutes generation without weakening citation, number or speaker checks. Settings now provide opt-in, signed in-app updates.

## 升级 / Upgrade

**0.3.0 没有更新器，需先手动安装 0.3.1 一次。之后 macOS、Windows 与 Linux AppImage 可在设置中升级。** Debian 系统包通过包管理器更新。

Update requests fetch only public version metadata and signed installers from GitHub. They send no audio, transcripts, notes, private configuration or hardware information. Recording, transcription and AI minutes remain offline. Shared profiles cannot enable update permission. Installation preserves the separate user-data directory.

安装包内置 Zipformer Small、Qwen3 1.7B Q4_K_M 及运行环境。OTA 校验签名与系统发行者签名不同：macOS 仍为临时签名、尚未公证；Windows 仍无发行者证书。其他平台限制见 [安装与验证说明](https://github.com/EazyLee30/omascribe/blob/v0.3.1/docs/NATIVE_TESTING.md)。
