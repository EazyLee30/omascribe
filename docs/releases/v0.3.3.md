# OmaScribe 0.3.3

本版改进低音量转写、连续纪要、术语纠正及说话人分配，并重新整理工作区与日常更新。

- 识别前对特别安静的音频做受限音量补偿，保留正常语音的音量及原始录音。修复较大转写模型缺少热词分词器时无法启动的问题；只在词表完全一致时复用本地分词器，热词不可用时继续转写。
- 纯试麦不再被写成“会议已完成”的纪要。跨轮整理保留先前证据，修复超过九条引用时最后一条事实无法提交的问题；人工确认段落和修订保护继续生效。中英文纪要采用明确的离线转写术语。
- 新增可重复运行的核心验收 harness：公开中英文音频评分、热词兼容、多轮纪要、说话人、人工保护、续录及长音频测试。失败保留草稿、原因与引用，中断输出不提交为正式纪要。运行方法及范围见 [CORE-HARNESS.md](https://github.com/EazyLee30/omascribe/blob/v0.3.3/docs/CORE-HARNESS.md)。

- 顶部使用会议标签页，支持新建、切换和关闭标签；关闭标签不会删除会议。顶栏空白区域可以拖动整个窗口。录音中的会议标签会保留。
- 默认采用黑白界面与红色强调色。笔记与面板融为一体，去掉固定编辑栏、外框和多余空边。外层不滚动，内容在各面板内部滚动。输入 `/` 插入标题、列表、待办、表格、时间戳等；选中文字才出现格式工具。
- 工作区采用 Dockview 组件：拖动面板可分栏、合并标签、浮动、最大化或隐藏。支持专注笔记、纪要阅读、三栏对照以及命名布局。
- 录音、计时、实时转写与字幕控制移入标题行，保持正文空间。实时转写直接打开系统级浮窗，能够移出主窗口。浮窗使用 Lucide 图标，直接显示录音计时、暂停／继续、结束、原文／双语／中译英／英译中和字幕；也可停靠回主窗口。
- 新增黑白像素机甲桌面小助手，使用 imagegen 绘制的 8 帧透明图集。小助手可拖动，点击展开录音、暂停／继续、结束、转写、字幕和翻译控制；启动时不自动录音，展开与收起保持相同机器人尺寸。隐藏后可从左下角「桌面助手」或「视图」菜单恢复。常规设置可关闭小助手或动效，并遵循系统减少动态效果设置。主界面同时提供醒目的“开始录音”入口。
- 笔记中的英文名称和启用的专有名词表接入本地 ASR 热词。明确的别名、误写和大小写在转写与待整理纪要中统一，原始转写修订保留；人工改写与人工保留的纪要不会被自动覆盖。模糊同音词仍需要核对，可将常见误写加入术语别名。
- 说话人分析可指定人数；重新分析使用手动命名的声音片段维持可靠的姓名对应。可将同一声音的其他自动片段一起分配，重叠、过短和不可靠的归属保持未分配。尚未做公开多说话人数据集的准确率评测。
- 官网 macOS 下载直接并列显示 Apple 芯片（M 系列）与 Intel，发布页提供五个安装包的直接下载表。

## 更新体积

完整安装包仍包含默认离线模型。从本版更新到后续版本时，客户端先校验并将内置模型保留在本机，再下载仅含程序与运行库的小更新包，避免每次重复下载约 1.1 GB 模型。这是组件拆分更新，尚不是二进制差分补丁。

**0.3.2 及更早客户端升级到本版，仍需一次完整更新。** 后续更新将使用新的精简更新通道。Linux Debian 包继续通过系统包管理器安装；AppImage 支持应用内更新。

所有更新必须验证签名；录音和本地内容处理期间不能安装。录音、转写、翻译和 AI 整理保持本地运行。仅主动检查／下载更新、下载模型或请求推荐时联网，不上传会议内容。

macOS 仍使用临时签名，尚未公证；Windows 仍无发行者证书。安装及平台说明见 [NATIVE_TESTING.md](https://github.com/EazyLee30/omascribe/blob/v0.3.3/docs/NATIVE_TESTING.md)。
