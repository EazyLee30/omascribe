# OmaScribe 0.3.4

修复笔记已经写明专名，转写和纪要仍沿用误识别名称的问题，并改进块编辑与分栏操作。

- 用户笔记中的名称同时用于本地识别热词、实时字幕、已完成转写和纪要标准拼写。较长英文专名支持有边界的拆词和近似拼写匹配，例如已写下 OmaScribe 时，`ALMA SCRIBE`、`奥马斯` 可以校正；同样适用于其他较长名称。
- 纪要缩减上下文或重试时继续保留名称约束，不再把专名只当作“关注”标签。短转写采用相应长度的纪要，避免为凑段落补写背景。
- 多轮整理替换自动段落前检查历史来源是否遗漏；缺失时先复核，不能静默覆盖旧稿。术语提示只在有名称上下文时启用。
- 本地模型专注生成纪要正文，代码负责绑定所用转写来源，减少同时编排正文与引用的负担。试麦、填充词较多时缩小写作要求，不强行补齐人物和安排。
- 去掉成文提示中固定列举的产品术语，减少含混短录音被扩写成原话没有的功能讨论；新增禁止补造议题和提示词泄漏的回归用例。
- 模型意外返回空纪要时保留待整理状态并复核，不再把尚未整理的原话显示为“已同步”；明确的纯试麦仍可直接略过。
- 普通英文句子不再逐词当作名称。相似名称有歧义、单独的短缩写或没有足够依据的中文近音词保留原文供核对；可在专有名词表中明确填写别名。
- 自动校正与人工修改分别记录来源。保留原始转写和修订历史，后续别名调整可更新自动结果，不覆盖人工确认的文字。旧版自动纪要在再次打开会议并整理时重新检查，人工保留段落继续受保护。
- 验收加入中英文通用名称、笔记不能变成会议事实、误替换反例和原文保护检查。新增本地录音回放工具，检查“笔记 → 热词 → 转写 → 带引用的纪要”整条流程。

- `/` 菜单按建议、基础块和会议工具分组，带图标、搜索与键盘选择。段落左侧提供插入按钮和拖动手柄；块菜单支持转换、复制、上下移动和二次确认删除，移动与删除可以独立撤销。
- 各栏标题移除容易被误认成删除的 `×`，改为菜单中的“隐藏此栏”，并说明可从“视图”恢复。重新显示三栏时分配更合理的宽度，也可手动均衡列宽；自定义堆叠布局保留。
- 纪要增加输出语言复核。旧会议中试麦钟点导致日期校验失败时，缩小概括范围重新整理，不编造会议时间变更。

**从 0.3.3 使用客户端检查更新，会下载程序与运行库的精简更新包，复用已校验的本地模型。** 官网首次安装包仍包含离线模型；0.3.2 及更早版本仍需一次完整过渡更新。此机制是组件拆分更新，不是二进制差分补丁。

录音、转写、校正、翻译和纪要均在本机处理，不上传会议内容。专名校正不是对所有口音、同音词或识别错误的准确率保证。
