# OmaScribe desktop companion

`notebook-mecha-atlas-v1.png` is an original transparent, 4 × 2 animation atlas generated with the built-in imagegen tool on 2026-10-25. Its 8 poses are read in row order: attentive, raised antenna, blink, attentive, listening, writing, wave, resting. The source is kept intact; the client displays individual cells with CSS background positioning and a grayscale filter. No remote asset or inference request is made at runtime.

Reference: the project's own `landing/public/assets/art/01-hero-mecha-small.webp` (mechanical notebook robot). The companion uses the same round camera eye, armor, pen and notebook, simplified to a chibi pixel mecha.
