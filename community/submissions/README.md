# Incoming submissions

Place a generated submission JSON here in a new branch and open a pull request. CI validates it but **does not publish it**. A maintainer reviews the public metadata, model combination and any measurement evidence, then moves an accepted file to `community/profiles/` without changing its `origin: "community"` or attribution. Only reviewed profiles are included in the gallery. Official suggestions live in the same published directory with `origin: "official"`.

Do not include meeting content, credentials or private paths. See [../README.md](../README.md).
